I lead hands-on quality engineering for high-load web, mobile, and backend products. My focus is building reliable delivery systems: maintainable automation, deterministic test environments, useful CI/CD quality signals, and tools that make teams faster without lowering confidence.

## Selected engineering work

| Project | Evidence |
|---|---|
| [ci-tests-manager](https://github.com/YauheniPo/ci-tests-manager) | A TypeScript service for dynamic E2E-test quarantine in CI/CD. It is Dockerized, persists filters in MongoDB, exposes an API contract, and uses a fail-open design so an unavailable service cannot block delivery. |
| [aissert](https://github.com/YauheniPo/aissert) | Evaluation harness for agent skills: fact-level LLM judges, deterministic precision/recall gates, golden sets, canary checks, artifacts, and publishable Claude Code/Codex plugins. |
| [popot-bot-2.0](https://github.com/YauheniPo/popot-bot-2.0) | Self-hosted Telegram AI operator and consent-first Bot API project. It demonstrates reproducible VPS provisioning with Ansible, encrypted configuration, health checks, backups, observability, and a documented security model. |
| [players_api_automation](https://github.com/YauheniPo/players_api_automation) | Kotlin REST API automation framework using Gradle Kotlin DSL, REST Assured, TestNG, AssertJ, Allure, deterministic test data, parallel execution, code-style checks, and GitHub Actions. |

## Private-product impact

Most production work is in private repositories. Selected outcomes from that work:

- Led the automation platform and roadmap across 12 feature teams and 4 product lines; technical lead for 4 SDETs.
- Re-platformed cross-browser web regression to Playwright, increasing stability to 98%+ and reducing full runtime from 3 hours to 50 minutes.
- Built shared Kotlin Multiplatform modules and automation foundations used across web, iOS, Android, backend, and API testing.
- Introduced service virtualization, deterministic test data, and observability practices that cut flaky streaming tests by 85%.
- Integrated quality gates and automated validation into GitLab CI/CD for 200+ microservices.
- Built AI-assisted workflows around QA documentation, failure triage, and code review, reducing manual triage and documentation effort by about 25%.
